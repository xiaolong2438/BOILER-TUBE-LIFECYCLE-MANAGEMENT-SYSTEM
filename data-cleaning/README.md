本版（v9，规则 `film-records-physical-codes-v9`）依据源附件共 464 个来源候选全部导入：2026年1号机C修160条、2022年1号机A修152条、2021年2号机A修152条。91个汇总弯头已经在总文件中。源表重复的“第24屏”记录经用户确认实为**第27屏**，已按 `1G-GGRQ-GQ-L027-F001-W` 导入（原第29行 L024 保留）。

## 编码规则（v9：字母尾物理编码 + 12回路分段基准 + 描述瘦身）

- 编码 = 位置 + Q/W 字母尾，例如 `1G-GGRQ-GQ-L002-F004-W`。**Q/W 后面不再带流水数字**：位置段已唯一确定这根管/弯头，尾号曾只是当年检修清单的流水，去掉后同一根管所有年份的记录都挂在同一编码下，历史检索与查重天然唯一。
- W 表示弯头，Q 表示管子；同位置的 Q 和 W 是同一根管的两个部位。
- **导入「详细描述/结论」只含检测内容**：`方法：射线；结果：合格`（异常行含“发现异物，割开检查为氧化皮”等原文结论）与待确认提示。批次、来源ID、位置、依据注记、原备注等溯源信息全部在导入表专属列与审计工作簿（`数据清洗审计.xlsx` 的“全量候选”页），不堆进描述。
- **同来源ID重导=更新**：系统按来源ID识别同一条源记录，重导本包会把既有记录的描述刷新为最新文本（导入完成提示“更新同源记录 N 条”），不会产生重复；此前导过 v7/v8 包的记录无需手工清理。
- **高过材质/规格按12回路分段基准推导（图纸148M211-0 + 用户2026-10-31确认）**：每回路 = 前腿F00k（顶部入口联箱向下）+ 底部弯头 + 后腿F(25−k)（向上至顶部出口），材质沿整个回路连续变化。W 记录对应底部弯头件（=前腿末段）：回路1=Φ54×7.5 TP347H、回路2-4=Φ51×8 TP304H、回路5-7及12=Φ51×8 T91、回路8-11=Φ51×9 12Cr1MoVG。据此 T91 底弯规格由 Φ51×9 修正为 **Φ51×8**（76条）。分段基准表已内置于系统「受热面设计图纸」页。
- 批次流水号不再进入编码，只保留在导入表的“批次流水号”溯源列和审计表，用于与源表逐条核对。
- 旧格式（`…-W001`）在导入、手工录入和编辑时自动归一为字母尾，历史数据无需手工改码。
- 同一编码在不同年份出现多条记录 = 同一部位的历年复检，系统按日期+内容区分，不会误判重复。

## 核对边界（均已确认/核定）

- **高过几何**：每屏 24 根管，F001–F024 ↔ B024–B001，L001–L032 ↔ R032–R001。系统与清洗都按此镜像归一：源“炉后第1根”的 32 条编码落成规范方向 `F024`；A 侧 `R007` 落成 `L026`。
- **高过材质/规格全部有据**：按12回路分段基准推导（2026第4/5行32条 + 2022/2021高过152条），底部弯头材质沿管位对称，与源表备注24弯头区带逐管互证。每条的映射依据记录在审计表“材质依据/规格依据”列。
- **高再材质**：仍按前7根区带映射（F001=TP304H、F002-004=T91、F005-007=12Cr1MoVG，规格 Φ60×4）；高再回路分段表待高再材料分界图提供后照高过办理。
- **规格经图纸核定**：304H 底弯=Φ51×8（第38行64个弯头源表 Φ54×7.5 为笔误已更正）；T91 底弯=Φ51×8（回路分段基准，修正此前配对的 Φ51×9）；12Cr1MoVG 底弯=Φ51×9；TP347H 底弯=Φ54×7.5。
- **材质全称统一**：SA-213TP304H、SA-213TP347H、SA-213T91（T91 简写归一）、12Cr1MoVG（源表 12CrMoVG 经确认实为 12Cr1MoVG）。
- **日期为检修月份**：`2026-04` / `2022-10` / `2021-11`（用户确认），日未提供、不填造。月精度可做检修覆盖统计；精确测厚/硬度预测不使用非完整日期的测点。
- 5个异常位置只转录“发现异物，割开检查为氧化皮”，没有追加质量判定。
- 旧 U/D 管圈编码（每屏12）为历史演示口径，与每屏 24 根的对应关系未确认，两套编号不互相换算。

## 旧包与新包不能叠加

本版编码去掉了流水数字，与此前所有版本的编码不同；v9 相对 v8 仅瘦身描述列（方法/结果），记录内容与编码不变。此前373条加91条的旧版数据存在编号和材质推断错误，已移到本地 `archive/`（不随Git发布）。v7/v8 包导入过的记录：直接重导本包即可按来源ID原位更新描述，不会重复；不要清空全部业务数据。

## 复现与完整性

```bash
python -m pip install openpyxl==3.1.5
python scripts/clean_boiler_film_records.py --input "/path/to/锅炉拍片记录1.xlsx" --outdir "/path/to/new-output"
python tests/test_clean_boiler_film_records.py
```

源附件只读。输出使用临时目录构建、回读核验、SHA256清单，全部成功后一次发布；目标目录已存在但内容或规则不同会拒绝覆盖。`verified/manifest.json` 保存全部来源行、隔离原因、记录映射、源文件及产物指纹。固定工作簿元数据时间仅用于字节级可重复构建，不代表检修日期。

系统行为：导入/录入/编辑时旧数字尾自动归一为字母尾；Q/W 记录按管位汇总检查证据（同管任一部位发现异常，管段档案状态会提示）；测厚和硬度序列按部位区分且只使用完整日期，更换登记之后的记录才计入当前管；台账矩阵与智能建议均使用字母尾编码。「受热面设计图纸」页内置高过12回路材质分段基准表（与清洗脚本单一事实源同步，有测试保证两端一致）。仅有结构校验或参考矩阵匹配，并不证明现场几何关系已确认。
