## 核对边界

- 流水号按每个检修批次源清单顺序连续且唯一。W表示弯头，Q表示管子；尾号不是物理弯头编号，不能拿它分配材质。
- 原表第24屏重复、第27屏缺项并不能证实后一次应改成27。本版保留原24屏、隔离重复候选，没有生成第27屏合格记录。
- 336条多值材质、224条多值规格没有逐管对应证据，单值列留空。原始候选、备注和来源全部保留在说明、审计表和manifest。
- 源数据只有年份，日期是文本 `2026` / `2022` / `2021`；不填造 `01-01`。检查覆盖可按年查看，精确测厚/硬度预测不使用只有年份的测点。
- 第38行64个弯头的规格全部保留源值 `Φ54×7.5`、材质 `304H`；5个异常位置只转录“发现异物，割开检查为氧化皮”，没有追加质量判定。
- 高过从炉前往后计数使用F；炉后第一根保留B001。每屏实际独立管根数及与旧U/D管圈的关系未确认，不能据“24弯头”推定24根管，更不能把B001自动换成F024。

## 旧包与新包不能叠加

本次修正重新编排了批次流水号。此前373条加91条的旧版数据存在编号和材质推断错误，已移到本地 `archive/`（不随Git发布）。如果已经导入旧包，请先备份，在明确选中旧记录后迁移/替换；不要仅依赖“重复导入自动跳过”，不要清空全部业务数据。

## 复现与完整性

```bash
python -m pip install openpyxl==3.1.5
python scripts/clean_boiler_film_records.py --input "/path/to/锅炉拍片记录1.xlsx" --outdir "/path/to/new-output"
python tests/test_clean_boiler_film_records.py
```

源附件只读。输出使用临时目录构建、回读核验、SHA256清单，全部成功后一次发布；目标目录已存在但内容或规则不同会拒绝覆盖。`verified/manifest.json` 保存全部来源行、隔离原因、记录映射、源文件及产物指纹。固定工作簿元数据时间仅用于字节级可重复构建，不代表检修日期。

系统用已确认的方向范围进行归一；F/B现场位置总数未知时原码保留。Q/W记录按管位汇总检查证据，测厚和硬度序列仍按部位及更换版本区分，不混入另一部位的测点。仅有结构校验或参考矩阵匹配，并不证明现场几何关系已确认。
