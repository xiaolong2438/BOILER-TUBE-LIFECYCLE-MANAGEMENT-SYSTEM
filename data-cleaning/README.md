## 编码规则（v5：字母尾物理编码 + 已确认几何与区带）

- 编码 = 位置 + Q/W 字母尾，例如 `1G-GGRQ-GQ-L002-F004-W`。**Q/W 后面不再带流水数字**：位置段已唯一确定这根管/弯头，尾号曾只是当年检修清单的流水，去掉后同一根管所有年份的记录都挂在同一编码下，历史检索与查重天然唯一。
- W 表示弯头，Q 表示管子；同位置的 Q 和 W 是同一根管的两个部位。
- 批次流水号不再进入编码，只保留在导入表的“批次流水号”溯源列和审计表，用于与源表逐条核对。
- 旧格式（`…-W001`）在导入、手工录入和编辑时自动归一为字母尾，历史数据无需手工改码。
- 同一编码在不同年份出现多条记录 = 同一部位的历年复检，系统按日期+内容区分，不会误判重复。

## 核对边界

- 原表第24屏重复、第27屏缺项并不能证实后一次应改成27。本版保留原24屏、隔离重复候选，没有生成第27屏合格记录。
- 材质/规格已全部填入：2026第4/5行32条按每屏24根区带映射，2022/2021全部304条按前12根（高过）/前7根（高再）区带映射——用户已确认 F001 起为炉前至炉后第1根，备注“炉后往炉前数”为方向笔误（与2026区带在前12根逐位互证）。每条的映射依据记录在审计表“材质依据/规格依据”列。
- 12CrMoVG 按源表保留，未改成系统材料库常见的 12Cr1MoVG（两者为不同牌号，需材料专业确认）。
- 源数据只有年份，日期是文本 `2026` / `2022` / `2021`；不填造 `01-01`。检查覆盖可按年查看，精确测厚/硬度预测不使用只有年份的测点。
- 第38行64个弯头的规格全部保留源值 `Φ54×7.5`、材质 `304H`；5个异常位置只转录“发现异物，割开检查为氧化皮”，没有追加质量判定。
- **高过几何已确认（用户口径）**：每屏 24 根管，F001–F024 ↔ B024–B001，L001–L032 ↔ R032–R001。系统与清洗都按此镜像归一：源“炉后第1根”的 32 条编码落成规范方向 `F024`；A 侧 `R007` 落成 `L026`。
- 2026 第4/5行 32 条的材质/规格已按备注“炉后往炉前数”区带 + 管位映射（如 F004=炉后第21弯头→304H/Φ51×8），材质候选保留原牌号全称；2022/2021 的 12/7 弯头区带对应（前12根还是后12根、计数方向）仍未确认，材质留空待核。
- 旧 U/D 管圈编码（每屏12）为历史演示口径，与每屏 24 根的对应关系未确认，两套编号不互相换算。

## 旧包与新包不能叠加

本版编码去掉了流水数字，与此前所有版本的编码不同。此前373条加91条的旧版数据存在编号和材质推断错误，已移到本地 `archive/`（不随Git发布）。如果已经导入旧包，请先备份，在明确选中旧记录后迁移/替换；不要仅依赖“重复导入自动跳过”，不要清空全部业务数据。

## 复现与完整性

```bash
python -m pip install openpyxl==3.1.5
python scripts/clean_boiler_film_records.py --input "/path/to/锅炉拍片记录1.xlsx" --outdir "/path/to/new-output"
python tests/test_clean_boiler_film_records.py
```

源附件只读。输出使用临时目录构建、回读核验、SHA256清单，全部成功后一次发布；目标目录已存在但内容或规则不同会拒绝覆盖。`verified/manifest.json` 保存全部来源行、隔离原因、记录映射、源文件及产物指纹。固定工作簿元数据时间仅用于字节级可重复构建，不代表检修日期。

系统行为：导入/录入/编辑时旧数字尾自动归一为字母尾；Q/W 记录按管位汇总检查证据（同管任一部位发现异常，管段档案状态会提示）；测厚和硬度序列按部位区分且只使用完整日期，更换登记之后的记录才计入当前管；台账矩阵与智能建议均使用字母尾编码。仅有结构校验或参考矩阵匹配，并不证明现场几何关系已确认。
