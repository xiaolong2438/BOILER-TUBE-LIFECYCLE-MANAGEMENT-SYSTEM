# 基础温度测点台账

两台机组的基础温度测点清单，供超温模块建点及每月越限报表匹配使用。

## 文件

- `基础温度测点台账.xlsx`：正式台账（测点台账 + 分类汇总）
- `基础温度测点台账.csv`：同内容纯文本版，便于版本比对和脚本读取

重新生成：

```bash
python -I scripts/build_temperature_point_ledger.py
```

## 与月报的对应关系

月报列与本台账的匹配方式：

| 月报列 | 对应字段 | 说明 |
|---|---|---|
| 点位 | `DCS Tag` | 机组内唯一，作为匹配主键 |
| 描述 | `测点名称` | 辅助核对，不用作唯一键 |
| 限值 ? | `温度限值(℃)` | 入库前核对是否与当时有效配置一致 |
| 最值 | 事件温度 | 事件区间内的最高值 |
| 开始时间 / 结束时间 | 事件起止 | 转为毫秒时间戳 |
| 总时长(秒) | — | 实际内容为 `HH:mm:ss`，须解析并与起止时间差核对 |

同一测点同月可有多条越限事件，应全部保留；累计时长按事件区间并集计算，重叠时段不重复计时。重复上传同一文件时按“点位 + 起止时间 + 越限类型”等来源指纹去重。

## 月度超温清洗产物

DCS 原始月报先用脚本按“每月哪些点超温、超温多久”清洗，再导入超温模块：

```bash
python scripts/clean_overtemperature_report.py "D:/路径/result.xls"
```

每次输出四个数据文件和一个审计文件，文件名带月份与机组：

- `月度超温报表_<月>_<机组>号机.csv/.xlsx`：标准导入表，按事件保留明细；xlsx 内同时含“月度报表”和“点位月累计”两个工作表。
- `月度超温点位累计_<月>_<机组>号机.csv/.xlsx`：每个超温点一行的当月累计，供核对和汇报。
- `月度超温清洗审计_<月>_<机组>号机.json`：来源、事件数、超温点数、累计秒数和需处理项。

`管屏` 列保留为空，待机组检修时按现场实际确认后补填；脚本拒绝一次处理跨月文件，避免把不同月份的累计混在一起。超温模块导入时，未登记点位会按报表自动建点，管屏同样留空。

跨月、跨年累计由系统累计分析页按同一测点自动汇总：先把事件区间并集为月度合计，再把同一测点的各月合计按年度累加；不同测点即使描述相同也不合并。
